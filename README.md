# 🔍 DeepDue AI — Financial Risk Intelligence System

DeepDue AI is an AI-powered financial document analysis and risk assessment system that automates document processing, fraud detection, and risk scoring using Machine Learning and statistical techniques.

## 🚀 Features
- Document Ingestion
- OCR (EasyOCR / PaddleOCR)
- Classification
- Data Extraction
- Fraud Detection
- Isolation Forest
- Benford’s Law
- Risk Scoring
- FastAPI Backend
- Streamlit Dashboard

## ⚙️ Setup
1. Create venv
2. Install dependencies
3. Run init_db
4. Run pipeline
5. Start API
6. Run dashboard
